# 🔥 Featured Projects

## 🎬 AniMaze

### Anime Discovery & Streaming Platform

AniMaze is a full-stack anime website where users can discover anime, search for shows, view detailed information, and stream episodes.

### Features

- 🔥 Trending anime
- 🔎 Anime search
- 📖 Anime details
- 🎬 Episode system
- ▶️ Video streaming
- 🎙️ SUB / DUB support
- 📝 Subtitle support
- 🎯 Recommendations
- 🌙 Dark / Light mode
- 📱 Responsive design

### Built With

  <img src="https://skillicons.dev/icons?i=python,fastapi,js,html,css,tailwind,graphql,vercel" />
</p>

**Also used:** AniList • Consumet • HLS.js • Plyr • Jinja2 • HTTPX • AsyncIO
